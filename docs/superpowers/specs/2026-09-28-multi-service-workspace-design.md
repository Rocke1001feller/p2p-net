# P1 多服务工作台 UI 改造 — 设计 spec（2026-09-28）

> 原型：`docs/prototypes/product-model-v2.html`（P0 已定稿：设备页=启动台，工作台=侧栏树+沉浸式）。
> 模型：`docs/prototypes/product-model-v1.md`。本 spec 只覆盖 P1（PWA UI 改造），不含发布管道（P2）/支付（P4）。

## 1. 背景

9-28 取证：PWA 工作台只直载「被裁决的一个」服务（console 自述 > p2p-net 命名 > last-good/清单首个），其余服务无用户可见入口。裁决链防劫持有功，但把「多服务」这个天生能力藏掉了。9-27 重启事件实证：唯一候选错误时（Kimi Code 57255），用户被静默带错地方。

## 2. 目标

1. 服务清单一等公民化：一台设备上所有自动发现的服务**默认全部可见、可切换**。
2. 减法模型：用户唯一操作是「隐藏」（不显示但仍挂载），可恢复；无「手动添加服务」入口。
3. 沉浸式工作台：进入某服务后，header（connbar）/底部 tabbar/侧栏树全部收起，屏幕全给服务；底部「∧ 唤起」把手召回，4s 无操作再收起。
4. console 锚定降级：从「唯一可见服务」改为「默认首页服务」（开工作台时的初始选中），不再遮蔽其余服务。
5. 设备页改为启动台：设备卡片 × 服务图标网格，点图标直达工作台对应服务（沉浸）。
6. **默认落地页 = 设备页**（启动台），不是工作台（2026-09-28 用户裁决）。

## 3. 非目标

- 不改扫描器判定规则（Kimi Code 上架是合法行为；治理另议）。
- 不改级联/通道逻辑（P2P>隧道>中继 与通道徽章原样保留）。
- 不动多设备连接管理（现有设备列表→连接逻辑保留，只是入口 UI 换成启动台）。
- 不做支付（P4 另立 spec）。

## 4. 设计

### 4.1 数据与持久化

- `hiddenServices`: localStorage，按 `deviceId` 分键：`{"<deviceId>": ["57255", ...]}`。跨设备隔离，换机不串。
- `lastService`: 按 `deviceId` 记上次选中服务端口（复用 last-good 通道，扩展为 per-device）。
- console 自述（`consolePort`）保留：仅作为工作台的初始默认选中；该服务被用户隐藏时也照常列在树里（隐藏≠不可选……**裁决：console 服务不可隐藏**，它是设备的「主页」，✕ 不渲染）。

### 4.2 结构（PWA shell）

```
设备页（启动台）          工作台（immersive workspace）
 设备卡片×服务网格   →     侧栏抽屉（设备树×服务列表 + 隐藏/恢复）
                            └── 服务 iframe 全屏区（tabs: per-port iframe 复用现有）
「我的」页不变（本 spec 不含订阅 UI，原型里的套餐卡仅是 P4 占位）
```

- 侧栏抽屉：默认收起；☰ 把手或从「设备页」进服务前短暂可见；点服务即收起并进入沉浸。
- 沉浸唤起：底部居中半透明 `∧ 唤起` pill（仅在沉浸时存在）；点按退出沉浸 → 4s 无交互自动回沉浸（仅当仍有选中服务）。
- 通道变化（隧道↔P2P 升降级）**不**打破沉浸：徽章本来就看不见，重连不重建已有 W-B① 保证。

### 4.3 iframe 池

- 复用现有 `tabs: Map<port, {iframe, booted…}>`：每服务一个 iframe，切换=显隐，不重建（保住 W-B 成果：现场不丢）。
- 服务从清单消失（进程死了）：iframe 保留 + 服务行灰显「已离线」；不自动隐藏（用户没做减法就不能替用户减）。
- 工作台首屏无选中：显示引导页（「☰ 从侧栏挑一个服务」），不弹 sheet。

### 4.4 与现有代码的接口

- `openWorkbench()` 的端口裁决链：**拆成两半**——`consolePort` 只产出「默认选中」；`currentServices` 全量进侧栏树。`pickFallbackPort`/last-good 逻辑改作「上次选中恢复」。
- `?svc=<port>` 验收钩子保留，语义不变（直开指定服务，跳过默认选中）。
- `__p2pNetDebug().services` 保留。
- W-B①（重连探活不重建）、W-B②（位置记忆在 iframe 内）不受影响；②的 `workspace-location` 是服务内记忆，与服务的显隐正交。

### 4.5 错误与边界

| 场景 | 行为 |
|---|---|
| 全部服务被隐藏 | 工作台显示「已全部隐藏」+ 恢复入口；不弹离线条 |
| console 端口死了 | 默认选中落空 → 引导页；不 hijack 到其他服务 |
| 设备离线 | 启动台卡片灰显 + 现有「设备不在线」sheet |
| 隐藏当前正在看的服务 | 允许；立即回引导页，iframe 保留（恢复后现场还在） |

## 5. 测试

- 单测（现有 harness + installFakeRtc 不变）：
  - 服务树渲染：console 不可隐藏；隐藏/恢复持久化 per-device 隔离；
  - 默认选中链：console 优先 → lastService 粘性 → 引导页兜底（不再「清单首个」盲选）；
  - 沉浸状态机：openService→沉浸、wake→退出、4s 超时回沉浸、切 tab 退沉浸；
  - 服务消失灰显不自动隐藏；全部隐藏引导页。
- 真机门禁：双机各连一台设备、每台 ≥2 服务，验证切换零重载（W-B 回归）+ 隐藏/恢复 + 沉浸唤起。
